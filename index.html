Fine-Tuning LLM with LoRA & Quantization

HuggingFace · PEFT · LoRA · bitsandbytes · Gemma-7B

Fine-tuned Gemma-7B on 945K+ customer support tweets using LoRA (r=64) and 8-bit quantization. Full 7B fine-tune on a single GPU, eliminating multi-GPU infrastructure.

LoRA / PEFT Quantization Gemma-7B LLMs
GitHub →

Pipeline

  • 945K input/response tweet pairs, tokenized max_length=512
  • LoRA on q_proj/v_proj: r=16, alpha=32, dropout=0.1
  • 8-bit loading via bitsandbytes for single-GPU training
  • AdamW + gradient accumulation; adapters checkpointed

Key decisions

  • LoRA: fast iteration, tiny artifact vs full fine-tune
  • 8-bit quantization: 60% memory reduction, no quality loss
  • Target q/v projections: best quality-cost tradeoff
  • 300-sample blind test for unbiased evaluation

Result

+14% response relevance vs base Gemma-7B. 62% win-rate in pairwise preference eval. 60% GPU memory reduction, enabling deployment on lower-cost infrastructure.

Approach

  • 28x28 grayscale to 3-channel RGB with transforms
  • Custom PyTorch Dataset + DataLoader ETL pipeline
  • VGG-16 & ResNet: frozen backbone, custom head
